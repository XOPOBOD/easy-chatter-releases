# Easy Chatter

Windows app for writing replies on social media. It works with your AI provider, on a subscription or an API key.

## Install

1. Download `Easy-Chatter-<version>-portable-x64.zip` from the [latest release](https://github.com/XOPOBOD/easy-chatter-releases/releases/latest).
2. Unzip it to any folder.
3. Run `Easy Chatter.exe`.
